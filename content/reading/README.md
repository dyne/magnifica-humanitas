# Opening reading edition

`en.json` authors four opening concepts and the two-step trail “Why is worth not
a reward?”. The complete concept library and six-trail release remain separate
editorial work. Stable concept, relationship, paragraph and reasoning-block IDs
support direct links and history; preserve them when editing wording.

The definitions, necessary distinctions, three directed relationships and §52
quotation reuse the accepted editorial model. New reasoning, transitions,
foundations and 31 paragraph-context paraphrases were checked against the frozen
source and coverage instructions for §§50–64, 71–72, 81, 102–107, 109, 154, 164
and 197–200. The review retained all four dignity meanings, rights' universal
foundation and concrete protection, the Church's abortion/euthanasia position,
migrants' complementary rights, ability-limited contribution, State and platform
responsibility, design-stage justice and all stated warfare conditions. This
writer's source comparison is evidence for supervisor review; it does not claim
independent reader testing or completed whole-library fidelity review.

Paraphrase, editorial interpretation, exact quotation and optional attributed
foundations remain separate. Necessary qualifications are always in the article.
No raw paragraph body is displayed, and no source fragments are spliced into a
quotation. None of the 31 opening paragraphs contains a ledger devotional
exclusion; validation still rejects the ledger's exact excluded forms in public
prose and quotation/exclusion overlap. Original source and ledger files remain
unchanged.

`scripts/reading-content.mjs` validates references and builds a bounded context
index at Vite build time. The lazy index contains reviewed context, source hashes,
PDF pages, editorial placement decisions and 39 screened bibliographic notes.
It excludes raw paragraph bodies and excluded devotional forms. The note
allowlist records the notes read for this opening edition; expanding it requires
review of each new note's exact wording. Notes retain original text and source
backlinks; “ibid.” provides a link to the preceding published citation.

Run `npm run content:check` and `node --test tests/reading-content.test.mjs` after
editing. Machine checks cover structural anchors and exact spans, not the full
semantic fidelity of newly authored prose. Read the source and editorial
contract before changing agency, qualifications, certainty or attribution.
