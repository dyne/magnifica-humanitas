# Decisions

## Confirmed by the owner

- New repository: `magnifica-humanitas`.
- Build a modern interactive Vite website using `vite-theme`.
- Base the content on the encyclical saved in this workspace.
- Analyze the source deeply; preserve its complexity rather than simplifying
  the argument. Add explanatory layers and connections.
- Serve readers who are not accustomed to long texts, especially on mobile.
- Remove religious prayers and liturgical formulas from the experience.
- Use Humanizer, Impeccable and a durable Org plan.
- Quiz the owner on consequential decisions.

## First quiz — confirmed

1. English first. Add languages later, beginning from each official encyclical
   translation rather than translating the English adaptation alone.
2. Secular primary paths; theological foundations in optional depth layers.
3. Interactive concept atlas as the leading experience. Guided trails and
   situations can serve as secondary routes into the material.

## Second quiz — confirmed

- Vue 3 + TypeScript within Vite.
- Publish to `dyne/magnifica-humanitas` on GitHub and GitHub Pages.
- Direct build: use the Dyne theme, prototype real interactions in code and
  review running mobile pages. Recorded in `.impeccable/config.json`.

## Remaining design work

Choose the concrete atlas composition during the design milestone, using the
existing Dyne visual language and actual source passages. This is a choice
within the confirmed atlas experience, not a reopening of product direction.
No custom domain is specified. GitHub Pages project-subpath output is required.

## Proposed defaults, not confirmed decisions

- Anonymous use, no accounts or analytics, local bookmarks and resume state.
- Authored explanations and search, no live chatbot interpreting the text.
- Six substantial trails, a connected concept library and a sequential adapted
  reading route; all content reachable without finishing a quiz.
- Public source references, an editorial-method page and paragraph coverage.
- Language-independent concept IDs; translations preserve source relationships.
